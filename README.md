## 📋 Sobre o projeto
Projeto em JavaScript que recebe uma sequência de caracteres contendo números, pontos e espaços, e retorna apenas os números.

## ⚙️ Como usar

1. Clone o repositório
2. Acesse a pasta do projeto
3. Instale as dependências:

```bash
npm install
```

4. Rode o aplicativo:

```bash
npm start
```

## 💡 Exemplo
Entrada: `"123.456 78.9"`
Saída: `"123456789"`
